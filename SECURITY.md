# Security Policy

## Reporting Security Issues

Please report security issues privately through GitHub private vulnerability reporting. Use the Security tab in the repository settings.

## Scope

This project covers the TaskbarIsland application and its source code. Engine binaries, installer scripts, and third-party tools are out of scope (they are separate projects with their own security contacts).

## Response Expectations

Security reports will be acknowledged within 5 business days. A triage estimate will be provided, and fixes will be prioritized based on severity. Critical issues affecting call control or data exposure will receive the highest priority.

## Preferred Contact

Use GitHub private vulnerability reporting. Do not disclose security issues in public issues, PRs, or discussions until a fix is released.

---  
This project is provided as free software under GPL-3.0-or-later. The author's primary incentive is personal use, not commercial security assurance. Report issues responsibly.
